# Sort 0s, 1s and 2s

A Java program to sort an array containing only 0, 1 and 2.

## Features

- Takes 0, 1 and 2 as input
- Sorts the elements
- Displays the sorted array

## Technologies Used

- Java
- Arrays
- Scanner

## Concepts Used

- Arrays
- Two pointer technique
- While loop
- Swapping

## Output

Sorted array: 0 0 1 1 2 2
